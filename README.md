Welcome to Medival Combat!

Medival Combat is a mod focused on medival weaponry and combat.

It adds many weapons like Sabers, Halberds, Maces, Spears and Great Swords.

Each weapon has their own benefits, negatives, stats and use.

Some weapons have reach, some trade speed for damage. Some are faster, but exchange speed for lower damage, range or both.

WEAPON DESCRIPTIONS:
=

Saber: A weaker, but faster version of the Sword that protects you from 25% of taken damage. Can be used for Critical Hits.

Rapier: A weaker, but faster version of the Saber that protects you from 25% of taken damage. Can be used for Critical Hits.

Battle Axe: A slower, but more powerful version of the Sword that can cut wood. Can be used for Critical Hits.

Mace: A slower & less powerful version of the Battle Axe, but Critical Hits are much heavier.

Spear: Slightly slower & slightly less powerful than the Sword, but trades these stats for range.

Pike: Slower & less powerful than the Sword, but trades these stats for a lot more range.

Halberd: Much more powerful than any weapon, with some range advantage, but is a lot slower. Cannot be used for Critical Hits.

Great Sword: A slower and more powerful version of the Sword with more reach. Cannot be used for Critical Hits, but trades this for Sweeping Attacks.

Dagger: A weaker version of the Rapier. Cannot be used for Critical Hits. Lower range than any weapon, but trades this for the Fastest Attacks.
